# Satergo Offline Vault

An Android application that is intended to be used in conjunction with the [Satergo wallet](https://satergo.com).

This application encrypts and safe-keeps your seed phrase on an Android device that you can avoid connecting to the internet.
The Satergo desktop application can then send requests to the phone which you can accept after reviewing the transaction.
This way, if your computer is infected, it cannot access the seed phrase and if it tries to alter your transaction to send the coins or tokens elsewhere,
you can notice it on the Android device. The Android device cannot alter the transaction either, as the desktop application only
receives signatures which it attaches to the unsigned transaction.
